개인정보처리방침

시행일: 2026년 10월 26일 · 서비스 주소: https://mytubelib.com/

"MyTubeLib"(이하 "본 앱")는 사용자가 본인의 YouTube 계정에 있는 좋아요·싫어요 영상, 재생목록, 구독 채널을 한곳에서 검색하고 정리해 볼 수 있게 해 주는 웹 페이지입니다. 본 방침은 본 앱이 어떤 정보에 접근하고, 어떻게 쓰고, 어디에 보관하는지 설명합니다.

1. 접근하는 정보

사용자가 Google 계정으로 로그인하고 동의하면, 본 앱은 아래 권한 하나만 요청합니다.

  • https://www.googleapis.com/auth/youtube.readonly — YouTube 계정을 읽기 전용으로 조회

이 권한으로 다음 데이터를 읽습니다: 본인 채널 식별 정보(채널 ID, 채널 이름), 좋아요·싫어요 표시한 영상 목록, 재생목록과 그 안의 영상, 구독 채널 목록, 그리고 해당 영상의 제목·썸네일·길이·조회수·좋아요 수 같은 공개 정보. 본 앱은 YouTube 데이터를 수정·삭제·업로드하지 않습니다. 이메일 주소 등 다른 Google 계정 정보는 요청하지 않습니다.

2. 정보의 이용 목적

읽어 온 데이터는 사용자 본인의 화면에 목록으로 보여주고, 검색·정렬·필터링하는 용도로만 사용합니다. 그 외의 목적(광고, 프로파일링, 판매, 분석 등)에는 사용하지 않습니다.

3. 정보의 저장 위치와 전송

  • 별도의 서버가 없습니다. 본 앱은 정적 웹 페이지이며, 사용자의 브라우저가 Google(YouTube) API와 직접 통신합니다. 운영자는 사용자의 YouTube 데이터를 수집·전송·열람할 수 없습니다.
  • 임시 데이터: 불러온 데이터는 브라우저의 세션 저장소에 보관되며, 탭 또는 브라우저를 닫으면 삭제됩니다.
  • 저장된 데이터: 사용자가 "현재 데이터 저장"을 직접 눌렀을 때만 이 기기의 브라우저(IndexedDB)에 저장됩니다. 삭제하기 전까지 남아 있고, 같은 PC·브라우저를 쓰는 다른 사용자도 볼 수 있으므로 개인 PC에서만 저장하거나 사용 후 삭제 버튼으로 삭제하세요.
  • 액세스 토큰: 데이터를 불러오는 동안에만 사용하며, 불러오기가 끝나면 Google에 폐기를 요청하고 즉시 지웁니다. 토큰은 저장하거나 서버로 보내지 않습니다.
  • 환경 설정: 언어와 테마 선택은 이 기기의 브라우저(localStorage/IndexedDB)에만 저장됩니다.

4. 데이터 보호 방법 (보안 조치)

본 앱은 사용자의 YouTube 데이터를 다음과 같은 방법으로 보호합니다.

  • 서버 저장 없음: 별도의 서버·데이터베이스가 없어 운영자의 시스템에 사용자 데이터가 저장되거나 유출될 경로 자체가 없습니다. 데이터는 사용자의 브라우저 안에서만 처리됩니다.
  • 전송 구간 암호화: 본 앱의 페이지와 Google·YouTube API와의 통신은 HTTPS(TLS)로 암호화됩니다.
  • 최소 권한: 읽기 전용 권한(youtube.readonly) 하나만 요청하며, 이메일·프로필 등 다른 계정 정보는 요청하지 않고 어떤 데이터도 수정하지 않습니다.
  • 토큰 보호: 액세스 토큰은 브라우저 세션 저장소에서만 짧게 사용하고, 데이터 불러오기가 끝나면 Google에 폐기를 요청한 뒤 즉시 삭제합니다. 토큰은 장기 저장하거나 외부로 전송하지 않습니다.
  • 데이터 격리: 임시 데이터는 세션 저장소에, 사용자가 직접 저장한 데이터는 해당 기기의 IndexedDB에만 보관되며, 다른 사이트나 외부 서버와 공유되지 않습니다. 브라우저의 동일 출처 정책으로 다른 웹사이트는 이 데이터에 접근할 수 없습니다.
  • 웹 취약점 대응: 화면에 표시하는 모든 외부 데이터(영상 제목, 채널 이름 등)는 HTML 이스케이프 처리하여 스크립트가 실행되지 않게 하며, 인라인 이벤트 핸들러를 사용하지 않습니다(XSS 방지).
  • 접근 통제: 사용자 데이터에 접근하는 운영자 계정·서버·관리자 화면이 존재하지 않습니다. 소스 코드 저장소에는 사용자 데이터가 포함되지 않으며, 저장소 변경은 운영자 계정(2단계 인증 권장)으로만 가능합니다.
  • 사용자 통제: 사용자는 언제든 저장된 데이터를 삭제하고 Google 계정 설정에서 접근 권한을 철회할 수 있습니다.

5. 제3자 제공 및 공유

운영자는 사용자의 YouTube 데이터를 제3자에게 제공·판매·공유하지 않습니다. 다만 본 앱을 사용할 때 다음 외부 서비스와 통신이 발생합니다.

  • Google 로그인 및 YouTube Data API — 인증과 데이터 조회 (Google 개인정보처리방침)
  • Google Fonts — 글꼴 로드 시 사용자의 IP 주소 등이 Google에 전달될 수 있음
  • YouTube — 영상 썸네일 및 영상 재생 시

6. Google API 서비스 사용자 데이터 정책 준수

본 앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

7. 사용자의 권리와 데이터 삭제

  • 임시 데이터: 탭·브라우저를 닫으면 삭제됩니다.
  • 저장된 데이터: 앱 목록의 "삭제" 버튼으로 삭제하거나, 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.
  • 접근 권한 철회: Google 계정 > 보안 > 타사 앱 액세스에서 언제든 본 앱의 권한을 제거할 수 있습니다.

8. 아동

본 앱은 만 13세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 의도적으로 수집하지 않습니다.

방침이 바뀌면 이 페이지를 갱신하고 시행일을 수정합니다.

Privacy Policy

Effective date: October 26, 2026 · Service URL: https://mytubelib.com/

"MyTubeLib" (the "App") is a web page that lets you search and browse the videos you liked or disliked, your playlists, and your subscriptions in your own YouTube account. This policy explains what information the App accesses, how it is used, and where it is kept.

1. Information the App accesses

When you sign in with your Google account and give consent, the App requests only the following scope:

  • https://www.googleapis.com/auth/youtube.readonly — read-only access to your YouTube account

With this scope the App reads: your channel identity (channel ID and name), the list of videos you liked or disliked, your playlists and the videos in them, your subscribed channels, and public details of those videos such as title, thumbnail, duration, view count and like count. The App never modifies, deletes or uploads anything in your YouTube account. It does not request your email address or other Google account details.

2. How the information is used

The data is used only to display it to you as a list and to let you search, sort and filter it. It is not used for advertising, profiling, sale, analytics or any other purpose.

3. Where data is stored and whether it is transmitted

  • There is no server. The App is a static web page; your browser talks directly to the Google (YouTube) APIs. The operator cannot collect, receive or view your YouTube data.
  • Temporary data: loaded data is kept in the browser's session storage and is deleted when you close the tab or browser.
  • Saved data: stored in this device's browser (IndexedDB) only when you press "Save current data". It stays until you delete it, and other users of the same PC and browser can see it — save only on a personal PC, or delete it with the delete button after use.
  • Access token: used only while data is loading; when loading finishes the App asks Google to revoke it and erases it immediately. The token is never stored or sent to any server.
  • Preferences: your language and theme choices are stored only in this device's browser (localStorage/IndexedDB).

4. How we protect your data (security measures)

The App protects your YouTube data in the following ways.

  • No server-side storage: There is no backend server or database, so there is no place where user data is stored or could be leaked from the operator's systems. Data is processed only inside your browser.
  • Encryption in transit: The App's pages and all communication with the Google and YouTube APIs are encrypted with HTTPS (TLS).
  • Least privilege: The App requests a single read-only scope (youtube.readonly), does not request your email, profile or other account details, and never modifies any data.
  • Token protection: The access token is used only briefly in the browser's session storage. When loading finishes the App asks Google to revoke it and deletes it immediately. Tokens are never stored long-term or sent anywhere else.
  • Data isolation: Temporary data lives in session storage, and data you choose to save lives only in IndexedDB on your device. It is not shared with other sites or external servers, and the browser's same-origin policy prevents other websites from reading it.
  • Web vulnerability defenses: All external data shown on screen (video titles, channel names, etc.) is HTML-escaped so scripts cannot run, and inline event handlers are not used (XSS prevention).
  • Access control: No operator account, server or admin screen exists that can access user data. The source repository contains no user data, and changes to it can be made only through the operator's account (two-factor authentication recommended).
  • User control: You can delete saved data at any time and revoke the App's access in your Google Account settings.

5. Sharing with third parties

The operator does not provide, sell or share your YouTube data with any third party. Using the App does involve communication with these external services:

  • Google Sign-In and the YouTube Data API — authentication and data retrieval (Google Privacy Policy)
  • Google Fonts — loading fonts may send your IP address and similar details to Google
  • YouTube — for video thumbnails and when you play a video

6. Compliance with the Google API Services User Data Policy

The App's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Your choices and deleting data

  • Temporary data: deleted when you close the tab or browser.
  • Saved data: delete it with the "Delete" button in the App's list, or clear the site's data in your browser.
  • Revoking access: you can remove the App's access at any time under Google Account > Security > Third-party access.

8. Children

The App is not directed to children under 13 and does not knowingly collect information from children.

9. Changes to this policy

If this policy changes, this page will be updated and the effective date revised.
